# Even or Odd
This program checks whether a given number is even or odd using conditional statements in Java.
## 🧠 Logic
- A number is **even** if it's divisible by 2 (i.e., `num % 2 == 0`)
- Otherwise, it's **odd**
## ✅ Example
**Input:**
num = 7
**Output:**
7 is Odd

**Input:**
num = 88
**Output:**
88 is even
